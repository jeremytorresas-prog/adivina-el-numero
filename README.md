
# Adivina el número

Juego de consola en Python donde el programa elige un número entre 1 y 100
y tienes 7 intentos para adivinarlo. Después de cada intento te dice si
tu número es muy alto o muy bajo.

## Cómo ejecutarlo
    python adivina.py

## Lo que practiqué
- Bucles `while`
- Condicionales `if / elif / else`
- Módulo `random`
